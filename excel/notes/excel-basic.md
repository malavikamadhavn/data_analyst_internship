Microsoft Excel – Learning Notes


1. Introduction to Excel
Microsoft Excel is a spreadsheet application used to store, organise, calculate and analyse data.

Uses of Excel
Data entry and data management
Data cleaning
Calculations and formulas
Data analysis
Charts and reports
Creating dashboards

2. Basic Excel Terminology
Term| Meaning
Workbook| An Excel file
Worksheet| A sheet inside a workbook
Row| Horizontal arrangement of cells
Column| Vertical arrangement of cells
Cell| Intersection of a row and column
Cell Reference| Address of a cell, such as A1
Range| A group of selected cells

3. Types of Data
Text: Names and descriptions
Numbers: Sales and quantities
Dates: Transaction dates
Percentages: Growth rates
Currency: Prices and revenue
