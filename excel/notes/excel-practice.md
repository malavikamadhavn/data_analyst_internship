Exercise 1: Basic Calculations
1. Calculate total sales using SUM().
2. Calculate average sales using AVERAGE().
3. Find the highest sales using MAX().
4. Find the lowest sales using MIN().


Exercise 2: Conditional Formulas
5. Use IF() to identify sales above ₹30,000 as "High" and others as "Low".
6. Use SUMIF() to calculate total sales in the South region.
7. Use COUNTIF() to count Completed orders.
8. Use SUMIFS() to calculate South region Laptop sales.
9. Use COUNTIFS() to count Completed orders in the South region.


Exercise 3: Lookup Functions
10. Use VLOOKUP() to find the sales amount of employee Meera.
11. Use XLOOKUP() to find the product sold by employee Priya.


Exercise 4: Data Cleaning
12. Use TRIM() to remove extra spaces from employee names.
13. Use LEN() to count employee name characters.
14. Use CONCAT() to combine employee name and region.


Exercise 5: Business Analysis
1. Which region generated the highest sales?
2. Which product generated the highest sales?
3. How many orders are completed?
4. What is the average sales amount?
5. What business recommendations would you give based on the data?
